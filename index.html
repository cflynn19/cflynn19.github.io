Flow

An open-source visual debugger for asynchronous workflows and agent systems. Build a graph, run it, and watch every node resolve live — then open any past run and see what it actually did: which branch was taken, what really ran in parallel, and what a retried node returned the third time.

  • Token-based graph traversal — joins, branch pruning, and loops from one rule
  • Real concurrency; tests assert branches genuinely overlap
  • Events persisted before broadcast, so SSE reconnect resumes with no gap
  • One reducer drives both the live and the historical view
  • Seeded runs reproduce exactly; 76 tests against real PostgreSQL
  • TypeScript
  • React 19
  • Fastify
  • PostgreSQL
  • Drizzle
  • Zod

MIT licensed. Runs locally against your own Postgres — the seed data ships failures, retries, and anomalies so it looks lived-in immediately.

port-doctor

A zero-dependency CLI for the EADDRINUSE moment. Tells you exactly what is holding a port — process, command, user, how long it has been there — and offers to kill it, instead of sending you back to the lsof | xargs kill dance.

  • One scan whatever you ask for — a test asserts 500 ports still costs two calls
  • Refuses to signal anything in its own parent chain, even under --force
  • Sends SIGTERM and waits before it ever escalates to SIGKILL
  • Re-reads the port before signalling, so a recycled PID is never killed
  • JSON output and honest exit codes, for use in a predev script
  • Node.js
  • CLI
  • Zero dependencies

47 tests, no test framework. CI runs them on macOS, Linux, and Windows across Node 18, 20, and 22 — including a job that deletes lsof to exercise the ss fallback.
